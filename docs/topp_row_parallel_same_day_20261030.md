# Top-p 行并行：同日关闭开关的 4K 对照

同一天、同一份代码中，开启 top-p 行并行得到 **3688.33 total tok/s**，关闭得到 **3552.79 total tok/s**，本次差额为 **+3.815%**；平均 TPOT 从 84.12 ms 降至 80.86 ms（-3.875%）。两组共 2048 请求全部成功。

这是正向的一致性证据。当前仍选择 EXP20，top-p 保持默认关闭、作为待复核候选。顺序是先 B 后 A，A 是看到 B 结果后追加的对照，每组只有一个独立服务会话，不能据此声称稳定因果收益或统计显著。完整模型任务精度按用户要求暂缓，候选 16K 性能尚未测量。

## 优化前后与真实路径

原 launcher 的 program 数为 min(16,B)：B64 时一个 program 串行处理四行。候选改为 min(64,B)：B64 时每个 program 处理一行，并扩大共享 scratch 到 64 行。仍使用原 top-k/top-p JIT 内核，tile、筛选算法、表、warps/stages 和采样语义保持；本次没有增加新的算子融合。

生效范围是已验证的 BI-V150 单 GPU、FP32、词表 130560、B17..64、top-p-only 和受支持 stride。其他条件回退，B<=16 不享受这项行并行变化。既有 RoPE+KV 融合、GQA decode 八行布局/分页读取、prefill 页号广播和原 MLP 布局保持。

A 的独立子进程确认 install 返回 false，base/sampler 两个别名均指向原实现，正式服务没有候选 hook/grid/shadow 日志；原始 launcher 源码哈希、三个 top-p 编译变体及 TTIR 复核通过。A 再次核验 64 个 decode 和 64 个 prefill GQA 变体、42 个 MLP 模块/84 个权重节点、42 次 RoPE+KV 融合和 35 个 FULL 捕获尺寸，未发生路径偷换。

B 的正式计时无 shadow 检查。之前独立真实服务诊断的 B17..64 各两次、共 96 次逐元素 mask/RNG 检查已通过，另有 39 项设备入口/Graph/fallback 检查。这些验证不等于完整模型任务精度。

单算子微基准的 B64 截断阶段耗时下降 66.73%，与本次整模 +3.815% 是不同口径，不能相互替代；官方测评还包含 prefill、投影、小 batch 回退及服务开销。

## 失败、审核与保存
